# Arcana Type Indicator
# 阿尔卡那类型测评

## 说明
### 引言
我喜欢玩《女神异闻录》，当然也很喜欢游戏中的各种设定，其中就包括塔罗牌与人格面具。
众所周知，每个人格面具都有其对应的大阿尔卡那塔罗牌，代表其在人格中的一种表现。
游戏中有许多可以形成社群的角色，也有其特定的大阿尔卡那。 

这样的设定十分有趣对吧，那么我们也可以尝试把它拿到现实里来玩。
我们可以尝试给自己设定一个类似游戏里的大阿尔卡那，比如那些涉世未深，还在成长中，
而有着无限可能的人就可以是“愚者”。
### 实现
这样的想法在我高中毕业的那个暑假就有了，当然我也是那个时候玩了《P5R》和《P3R》。

在那个暑假，我刚好在初学编程，包括Python和C语言，那么我想我可以写一个测评程序来实现我的想法。
事实上，我确实这么做了，那是一个C语言程序。而众所周知，这种语言实现GUI是比较麻烦， 当时的程序也是不出意外的“黑框框交互”。

这样子的交互显然只能自己看看了。但现在不一样，我花了时间学习了前端，现在我完全可以轻易的实现舒服的交互界面（大概）。
当然，再次写这个程序也是因为最近SBTI的火热，同时我会把这个项目当做学习前端的练习。这就是为什么不直接AI生成。

## 大阿尔卡那列表（莱德 - 韦特体系）
0. 愚者 (The Fool) — 开端、天真、冒险、无限潜能
1. 魔术师 (The Magician) — 创造、资源、行动力、显化
2. 女祭司 (The High Priestess) — 直觉、潜意识、智慧、神秘
3. 女皇 (The Empress) — 丰收、孕育、母爱、自然、丰盛
4. 皇帝 (The Emperor) — 权威、秩序、结构、父权、掌控
5. 教皇 (The Hierophant) — 传统、信仰、导师、精神指引
6. 恋人 (The Lovers) — 爱情、选择、结合、价值观、和谐
7. 战车 (The Chariot) — 胜利、意志、控制、突破、前进
8. 力量 (Strength) — 勇气、内在力量、温柔、耐心、征服
9. 隐者 (The Hermit) — 内省、孤独、智慧、探索、引导
10. 命运之轮 (Wheel of Fortune) — 轮回、机遇、变化、宿命
11. 正义 (Justice) — 公平、因果、理性、真相、平衡
12. 倒悬者 (The Hanged Man) — 牺牲、等待、换视角、暂停、奉献
13. 死神 (Death) — 结束、转变、重生、告别、蜕变
14. 节制 (Temperance) — 调和、耐心、中庸、融合、自律
15. 恶魔 (The Devil) — 束缚、欲望、物质、恐惧、执念、阴暗面
16. 高塔 (The Tower) — 突变、毁灭、觉醒、意外、解放、骤变
17. 星星 (The Star) — 希望、灵感、宁静、疗愈、愿景、信心
18. 月亮 (The Moon) — 潜意识、恐惧、幻想、梦境、不安、幻象
19. 太阳 (The Sun) — 成功、喜悦、活力、光明、幸福、生命力
20. 审判 (Judgement) — 觉醒、重生、反思、召唤、清算
21. 世界 (The World) — 完成、圆满、整合、成就、旅程终点
