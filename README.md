## 简介
如你所见，你可以在这里测评你的阿尔卡那（Arcana）类型。

什么是阿尔卡那？我们都知道塔罗牌，标准的塔罗牌由78张阿尔卡那牌组成，其中包括大阿尔卡那和小阿尔卡那。而大阿尔卡那有22张，也就是这个ATI的测评空间。

如果你玩过《女神异闻录》系列的游戏，一定对这个不陌生。在游戏中，我们可以与一些NPC建立“社群”，这些NPC有着自己的阿尔卡那。例如《P5R》中的占卜师御船千早对应“命运”。

这样的设定也可以尝试应用到我们的世界，因此便有了这个ATI。在这个测评中，你需要完整回答42个问题！每个问题是一种描述，有5个选项（5个圆圈），从左至右的含义分别是： 

完全不符合、比较不符合、中立、比较符合、完全符合。

在完成所有问题后，你就可以获得结果：最符合你的5个阿尔卡那。我们不能简单地用一个阿尔卡那就概括一个人，因此你得到的是5个。

当然，这只是一个只有一些简单计算的测评，请不要过于当真。

### 最终结果判定规则
1. 计算22张牌面的「修正后得分」，取得分最高的1张作为测评结果（核心大阿尔卡那）。
2. 最终结果取分数前5的阿尔卡那。
### 程序适配补充
判分逻辑简化：统计每题得分→计算每张牌基础得分→排序→输出结果。
### 脚本与文件说明
一段一段的复制文本是很麻烦的，而纯前端似乎不能很好地对接一些脚本，所以我使用的是高级的复制粘贴法：让Python脚本处理好文本我再复制粘贴进JS里面。
其中的一些脚本是AI写的（正则化太反人类）
对应的一些用到的信息文本放在了*_in.txt文件中。这些文件放在了res下。

以下是脚本说明：
- ques_conv.py:用于将原始问题文本处理成可以写成JS数组的形式，对于作者标注暂未进行处理
- questions_list_conv.py：用于生成可以写成JS对象数组的文本，对象代表了一个问题应有的信息
- results_gen.py：用于生成可以写成JS对象数组的文本，对象代表了一个结果（阿尔卡那）应有的信息
- scores_list.py：用于将原始结果问题映射文本处理成可以写成JS数组的形式
