# Arcana Type Indicator
# 阿尔卡那类型测评

## 说明
### 引言
我喜欢玩《女神异闻录》，当然也很喜欢游戏中的各种设定，其中就包括塔罗牌与人格面具。
众所周知，每个人格面具都有其对应的大阿尔卡那塔罗牌，代表其在人格中的一种表现。
游戏中有许多可以形成社群的角色，也有其特定的大阿尔卡那。 

这样的设定十分有趣对吧，那么我们也可以尝试把它拿到现实里来玩。
我们可以尝试给自己设定一个类似游戏里的大阿尔卡那，比如那些涉世未深，还在成长中，
而有着无限可能的人就可以是“愚者”。
### 实现
这样的想法在我高中毕业的那个暑假就有了，当然我也是那个时候玩了《P5R》和《P3R》。

在那个暑假，我刚好在初学编程，包括Python和C语言，那么我想我可以写一个测评程序来实现我的想法。
事实上，我确实这么做了，那是一个C语言程序。而众所周知，这种语言实现GUI是比较麻烦， 当时的程序也是不出意外的“黑框框交互”。

这样子的交互显然只能自己看看了。但现在不一样，我花了时间学习了前端，现在我完全可以轻易地实现舒服的交互界面（大概）。
当然，再次写这个程序也是因为最近SBTI的火热，同时我会把这个项目当做学习前端的练习。这就是为什么不直接AI生成。

## 一、测评核心原则
覆盖全部22张大阿尔卡那（标准塔罗完整序列），每个牌面对应“人物核心特质+成长轨迹”。
测评题目缩减至44道（每张大阿尔卡那2题），兼顾场景化、趣味性和代入感，避免冗余；
采用“分值累加+权重修正”规则，每牌对应题目权重完全一致，确保22张牌出现概率均衡，
结果贴合测评者深层特质，适配程序批量判分。 22张大阿尔卡那完整序列：
0.愚者、1.魔术师、2.女祭司、3.女皇、4.皇帝、5.教皇、6.恋人、7.战车、8.力量、9.隐者、10.命运之轮、11.正义、12.倒吊人、13.死神、14.节制、15.恶魔、16.高塔、17.星星、18.月亮、19.太阳、20.审判、21.世界。
## 二、测评题目（共44题，每题1-5分，1=完全不符合，5=完全符合）

## 三、评测规则
### （一）分值统计规则
1. 每题按1-5分计分：1分=完全不符合，2分=不太符合，3分=中立，4分=比较符合，5分=完全符合。
2. 每张大阿尔卡那对应2题（场景决策题+特质倾向题），将2题分值相加，得到该牌面的「基础得分」；基础得分范围为2-10分，所有牌面分值结构完全对称，确保概率均衡。

### （三）权重修正规则
修正后得分=基础得分×权重系数，权重系数根据「特质倾向题平均得分」确定（简化计算，适配程序）：
1. 特质倾向题平均得分≥4分（外向/主动型）：愚者、魔术师、战车、太阳 权重系数+0.1；隐者、月亮 权重系数-0.1
2. 特质倾向题平均得分≤2分（内向/被动型）：隐者、月亮 权重系数+0.1；愚者、魔术师、战车、太阳 权重系数-0.1
3. 特质倾向题平均得分2-4分（中立型）：所有牌面权重系数=1.0（不修正）
### （四）最终结果判定规则（程序核心逻辑）
1. 计算22张牌面的「修正后得分」，取得分最高的1张作为测评结果（核心大阿尔卡那）。
2. 最终结果取分数前三的阿尔卡那。
3. 契合度说明：修正后得分≥8分=高度契合；5-7分=中度契合；2-4分=低度契合（程序可根据契合度输出对应描述）。
### （五）程序适配补充
- 判分逻辑简化：统计每题得分→计算每张牌基础得分→根据特质倾向题平均得分计算修正得分→排序取最高值→输出结果。
