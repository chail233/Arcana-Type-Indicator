# Arcana Type Indicator
# 阿尔卡那类型测评

## 说明
### 引言
我喜欢玩《女神异闻录》，当然也很喜欢游戏中的各种设定，其中就包括塔罗牌与人格面具。
众所周知，每个人格面具都有其对应的大阿尔卡那塔罗牌，代表其在人格中的一种表现。
游戏中有许多可以形成社群的角色，也有其特定的大阿尔卡那。 

这样的设定十分有趣对吧，那么我们也可以尝试把它拿到现实里来玩。
我们可以尝试给自己设定一个类似游戏里的大阿尔卡那，比如那些涉世未深，还在成长中，
而有着无限可能的人就可以是“愚者”。
### 实现
这样的想法在我高中毕业的那个暑假就有了，当然我也是那个时候玩了《P5R》和《P3R》。

在那个暑假，我刚好在初学编程，包括Python和C语言，那么我想我可以写一个测评程序来实现我的想法。
事实上，我确实这么做了，那是一个C语言程序。而众所周知，这种语言实现GUI是比较麻烦， 当时的程序也是不出意外的“黑框框交互”。

这样子的交互显然只能自己看看了。但现在不一样，我花了时间学习了前端，现在我完全可以轻易地实现舒服的交互界面（大概）。
当然，再次写这个程序也是因为最近SBTI的火热，同时我会把这个项目当做学习前端的练习。这就是为什么不直接AI生成。
